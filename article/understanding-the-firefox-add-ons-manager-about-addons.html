Understanding the Firefox Add-ons Manager (about:addons)

This article provides a quick overview of the Firefox Add-ons Manager, accessible via the internal address about:addons, and explains how it serves as the central hub for browser customization. You will learn what the Add-ons Manager is, how to access it, and the specific ways it categorizes, manages, and controls extensions, themes, and plugins to enhance your browsing experience.

What is the Add-ons Manager?

The Add-ons Manager is a built-in control panel in the Mozilla Firefox web browser. It allows users to discover, install, configure, update, and remove various software modules that modify the browser's capabilities and appearance.

You can open the Add-ons Manager using any of the following methods:

  • Type about:addons directly into the Firefox address bar and press Enter.
  • Use the keyboard shortcut Ctrl + Shift + A (Windows/Linux) or Cmd + Shift + A (macOS).
  • Click the three-line menu icon in the top-right corner of the browser and select Add-ons and themes.

The manager uses a left-hand navigation sidebar to neatly divide your browser modifications into specific functional categories: Extensions, Themes, and Plugins.

How It Organizes Extensions

Extensions are small software programs that add new features to Firefox or modify existing functionality, such as ad blockers, password managers, and grammar checkers.

In the Extensions tab, the Add-ons Manager organizes your installed tools into two primary groups:

  • Enabled: Extensions that are currently active and running in your browser.
  • Disabled: Extensions that are installed on your system but turned off.

Each extension is displayed as a card featuring a blue toggle switch to quickly enable or disable it, alongside a three-dot menu icon for quick actions like removing the extension. Clicking directly on an extension's name opens a detailed management view organized into three sub-tabs:

  • Details: Provides a description of the extension, version number, and toggles to allow automatic updates or grant the extension permission to run in Private Windows.
  • Permissions: Lists the specific browser data and system features the extension has access to, plus optional permissions you can toggle on or off.
  • Preferences: Available on select extensions, this allows you to configure the tool's specific settings directly within the about:addons tab.

How It Organizes Themes

Themes alter the visual appearance of the Firefox interface, changing the color scheme and background art of the toolbars, tabs, and menus.

In the Themes tab, the Add-ons Manager organizes visual styles into two sections:

  • Enabled: Displays the single theme that is currently active. Only one theme can be enabled at a time.
  • Saved Themes: Lists all other available themes. This includes Firefox's built-in defaults (System theme, Light, Dark, and Alpenglow) as well as any custom themes you have downloaded from the Firefox Add-ons store.

To switch your browser's look, you simply click the Enable button on any card in the Saved Themes section. It will immediately move to the Enabled section, and your previous theme will move down to the Saved list. You can delete downloaded themes from the Saved section using the three-dot menu, though built-in system themes cannot be removed.

How It Organizes Plugins

Plugins are specialized, third-party software libraries that help Firefox process specific types of web content it cannot handle natively. In modern versions of Firefox, legacy plugins like Adobe Flash are no longer supported; the Plugins section is now exclusively used for media codecs and Digital Rights Management (DRM) modules.

In the Plugins tab, Firefox typically lists two essential components:

  • OpenH264 Video Codec: Provided by Cisco Systems to support WebRTC video calls and H.264 video playback.
  • Widevine Content Decryption Module: Provided by Google to allow the playback of DRM-protected streaming media from services like Netflix or Spotify.

Unlike extensions and themes, you cannot browse a store to download new plugins, nor can you completely uninstall the default ones from this menu. Instead, the Add-ons Manager organizes them into a simple list where you can control their execution behavior. By clicking the three-dot menu next to a plugin, you can set it to Always Activate or Never Activate, giving you strict control over when these media modules are allowed to run.

Global Add-on Settings

At the top right of the Add-ons Manager interface, next to the search bar, is a gear icon. This menu provides global organization and management tools that apply to all categories. From here, users can manually check for updates for all installed add-ons, view recent update history, install an add-on directly from a local file (.xpi), or access the about:debugging page to test custom-built extensions.
