Firefox Quick Actions: Address Bar Commands Explained

This article explores the Quick Actions feature in the Mozilla Firefox address bar, explaining how it works and detailing the specific text commands you can use to instantly trigger built-in browser tools like taking a screenshot or clearing your history.

What are Firefox Quick Actions?

Quick Actions are interactive shortcuts built directly into the Firefox address bar. Instead of navigating through multiple menus or memorizing complex keyboard shortcuts, you can type a simple keyword or phrase into the address bar. Firefox will display a clickable action button in the dropdown menu that immediately executes the requested browser function.

To use a Quick Action, simply type the command into the address bar and either click the action button that appears with your mouse, or press the Tab key to highlight the button and press Enter.

Commands and What They Trigger

Here is a list of the primary Quick Actions available in Firefox and the exact functions they trigger when typed into the address bar:

  • "take screenshot" or "screenshot": Triggers the built-in Firefox screenshot tool, allowing you to instantly capture a specific region, the visible part of the webpage, or the entire page without opening the right-click context menu.
  • "clear history" or "delete history": Opens the "Clear Recent History" dialog box. From here, you can immediately select a time range and wipe your browsing history, cookies, cache, and active logins.
  • "addons", "extensions", or "themes": Opens the about:addons page, where you can manage, disable, or remove your installed browser extensions and visual themes.
  • "bookmarks": Opens the Bookmarks sidebar on the left side of your browser window, allowing you to search and organize your saved links.
  • "downloads": Opens the Firefox Library window directly to the Downloads tab so you can view your past downloaded files.
  • "passwords" or "logins": Opens the about:logins page, giving you direct access to the Firefox password manager to view, copy, or edit your saved credentials.
  • "settings", "options", or "preferences": Takes you straight to the main Firefox Settings page (about:preferences).
  • "print": Immediately opens the print preview and configuration dialog for the webpage you are currently viewing.
  • "private": Opens a new Private Browsing window, which does not save your browsing history or cookies after you close it.
  • "inspector": Launches the Firefox Web Developer Tools panel, focused on the HTML and CSS Page Inspector.
  • "view source": Opens a new tab displaying the raw HTML source code of the current webpage.
  • "refresh": Prompts the "Refresh Firefox" confirmation box, which is a troubleshooting feature that resets the browser to its default state while saving your essential data like bookmarks and passwords.
  • "update": Directs you to the settings menu to check if your browser is up to date and installs any pending Firefox updates.

How to Enable or Disable Quick Actions

Quick Actions are enabled by default in modern versions of Firefox. If you want to turn them off—or turn them back on—follow these steps:

  1. Type settings into the address bar and click the Open settings Quick Action button (or open Settings via the application menu).
  2. Click on Search in the left-hand menu.
  3. Scroll down to the Address Bar section.
  4. Check or uncheck the box next to Quick actions.
