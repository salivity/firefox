Add a Custom Search Engine to Firefox via OpenSearch XML

This article provides a step-by-step guide on how to add a custom search engine to the Mozilla Firefox web browser using a website's OpenSearch XML description file. By leveraging Firefox's built-in detection for the OpenSearch standard, you can quickly integrate site-specific search tools directly into your browser, allowing you to search your favorite websites straight from the address bar or search bar.

Prerequisites

Before you can add the search engine, the target website must properly host an OpenSearch XML description file and link to it within the <head> section of its HTML code. The link tag on the website must look like this:

<link rel="search" type="application/opensearchdescription+xml" title="Search Title" href="/opensearch.xml">

If the website has this configured correctly, Firefox will automatically detect the XML file when you visit the webpage.

Method 1: Using the Address Bar Context Menu

The fastest way to add an OpenSearch engine in modern versions of Firefox is directly through the address bar.

  1. Open Firefox and navigate to the webpage that contains the OpenSearch XML link.
  2. Right-click directly inside the address bar (URL bar) at the top of the browser.
  3. In the context menu that appears, look for the option labeled Add "[Website Name]" near the bottom of the list.
  4. Left-click this option. The custom search engine is now installed in Firefox.

Method 2: Using the Address Bar Drop-Down

You can also add the search engine using the one-off search buttons located at the bottom of the address bar's drop-down menu.

  1. Visit the website that hosts the OpenSearch XML file.
  2. Click once inside the Firefox address bar as if you are going to type a new URL.
  3. Look at the very bottom of the drop-down panel that appears, in the "This time, search with:" section.
  4. Locate the website's icon, which will feature a small green plus (+) badge over it.
  5. Hover over the icon to see the tooltip that says Add search engine, and click it to install.

Method 3: Using the Dedicated Search Bar

If you have enabled the optional, dedicated search bar next to your address bar in Firefox, you can use it to add the OpenSearch XML file.

  1. Navigate to the website offering the OpenSearch XML engine.
  2. Look at the magnifying glass icon inside the dedicated Search Bar. It will display a small green plus (+) symbol indicating an OpenSearch file was detected.
  3. Click the magnifying glass icon in the Search Bar.
  4. Click Add "[Website Name]" from the drop-down menu.

Managing Your Custom Search Engine

Once you have added the search engine via its OpenSearch XML file, you can make it your default search engine or assign it a custom shortcut keyword.

  1. Click the menu button (three horizontal lines) in the top-right corner of Firefox and select Settings.
  2. Click on Search in the left-hand navigation pane.
  3. Scroll down to the Search Shortcuts section to view your newly added search engine.
  4. Double-click the Keyword column next to your new search engine to assign a shortcut (for example, typing @custom in the address bar to trigger that specific search engine).
  5. To make it your primary search tool, scroll back up to the Default Search Engine section and select your new engine from the drop-down menu.
