Launch Firefox Profile Manager Using Command-Line Arguments

This article provides a quick and comprehensive guide on how to open the Firefox Profile Manager using the -P or --ProfileManager command-line arguments. By utilizing these specific flags, you can easily create, delete, rename, or switch between different Firefox user profiles to keep your browsing data and configurations separate. The following sections cover the necessary prerequisites and the exact steps required to execute these commands on Windows, macOS, and Linux systems.

Prerequisites

Before using the command-line arguments, you must completely close all running instances of the Firefox browser. If Firefox is already open in the background, running the command will simply open a new browser window in your current session instead of launching the Profile Manager.

Windows

You can launch the Profile Manager on Windows using either the Run dialog box or the Command Prompt.

Using the Run Dialog:

  1. Press the Windows Key + R on your keyboard to open the Run dialog.
  2. Type firefox.exe -P or firefox.exe --ProfileManager into the text box.
  3. Click OK or press Enter.

If Windows cannot find the program, you must enter the full path to the Firefox installation directory, enclosed in quotation marks: "C:\Program Files\Mozilla Firefox\firefox.exe" -P

Using Command Prompt:

  1. Open the Start Menu, type cmd, and press Enter.
  2. Type start firefox.exe -P or start firefox.exe --ProfileManager.
  3. Press Enter to open the Profile Manager.

macOS

To launch the Profile Manager on a Mac, you need to use the built-in Terminal application to target the Firefox binary directly.

  1. Press Command + Space to open Spotlight, type Terminal, and press Return.
  2. Enter the following command to use the -P flag: /Applications/Firefox.app/Contents/MacOS/firefox -P
  3. Alternatively, enter this command to use the --ProfileManager flag: /Applications/Firefox.app/Contents/MacOS/firefox --ProfileManager
  4. Press Return to execute the command.

Linux

Linux users can access the Profile Manager directly through their system's terminal emulator.

  1. Open your terminal application (commonly done by pressing Ctrl + Alt + T).
  2. Type firefox -P or firefox --ProfileManager.
  3. Press Enter.

Understanding the Arguments

Both -P and --ProfileManager accomplish the exact same task, and you can use them interchangeably. Keep in mind that these arguments are case-sensitive, particularly on Linux and macOS. You should always use an uppercase "P" for -P and the exact capitalization for --ProfileManager to ensure the interface opens properly.

If you want to bypass the Profile Manager GUI and launch a specific profile directly, you can add the profile's name to the end of the -P command, like this: firefox -P "ProfileName". Using --ProfileManager will always open the management window, as it does not accept a profile name after it.
