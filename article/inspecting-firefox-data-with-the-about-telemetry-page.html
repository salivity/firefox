Inspecting Firefox Data with the about:telemetry Page

This article explores how the about:telemetry page in the Firefox Web Browser empowers users with complete transparency over their browser's data collection. By accessing this built-in diagnostic tool, you can easily inspect every single metric, histogram, and environment ping recorded by your specific Firefox instance. We will break down how to access this dashboard, navigate its various data categories, and understand the technical payloads Firefox prepares to help improve browser performance and stability.

Accessing the Telemetry Dashboard

To view your browser's telemetry data, open a new tab in Firefox, type about:telemetry into the address bar, and press Enter. This opens a local webpage generated directly by your browser—no internet connection is required to view it.

In the top-left corner, you can control which dataset you are viewing. By default, the page displays Current data, which is the live information being gathered during your active browsing session. By clicking the configuration gear or changing the ping data source, you can switch to Archived ping data. This allows you to browse historical snapshots of data that have already been packaged and sent (or are waiting to be sent) to Mozilla, organized by date and ping type (such as "main", "event", or "health").

Inspecting Environment Pings

The Environment Data section outlines the technical context in which your browser operates. Mozilla uses this to determine if a browser crash or performance issue is tied to specific hardware or software configurations. Clicking on Environment Data in the left-hand sidebar reveals several collapsible subsections:

  • Build and Partner: Displays the exact Firefox version, build ID, update channel (e.g., Release, Beta, Nightly), and system architecture.
  • System: Reveals your operating system version, CPU specifications, total system memory (RAM), and detailed graphics card and driver information.
  • Settings: Lists your locale, default search engine, telemetry preferences, and a curated list of non-default about:config preferences you have modified.
  • Add-ons: Provides a complete inventory of your active extensions, themes, and plugins, including their version numbers and installation dates.

Reading Metrics, Scalars, and Events

Firefox records discrete, straightforward data points using Scalars and Events. These are the easiest metrics to read on the about:telemetry page because they represent single values rather than complex distributions.

  • Scalars: Located in the left sidebar, the Scalars section displays single values such as numbers, booleans (true/false), or strings. These track simple metrics like the total number of tabs opened during a session, the duration of a session, or whether a specific browser feature was used.
  • Keyed Scalars: These function like standard scalars but group the data under specific labels (keys). For example, instead of just counting total searches, a keyed scalar will count how many searches were performed per specific search engine or location (e.g., URL bar vs. Search bar).
  • Events: The Events section logs specific user interactions or browser occurrences alongside a timestamp. This provides a chronological record of how features are interacted with, detailing the category, method, and object of each action.

Analyzing Histograms

For complex performance metrics, single numbers are insufficient. Firefox uses Histograms to measure the distribution of thousands of values over time, such as how many milliseconds it takes to paint a webpage, how long garbage collection takes, or how much memory the browser is consuming at different intervals.

When you click on Histograms or Keyed Histograms, about:telemetry renders visual bar charts for each metric. Instead of logging every individual measurement separately, Firefox groups the measurements into ranges called "buckets."

When looking at a histogram on the page, you can instantly read:

  • The X-axis: The value of the measurement (e.g., time in milliseconds or memory in megabytes).
  • The Y-axis: The number of times a measurement fell into that specific bucket.
  • Summary Statistics: Directly above the chart, Firefox displays the total number of samples collected and the total sum of all measurements, allowing you to quickly see if a browser process is consistently fast or experiencing occasional lag spikes.

Searching and Viewing Raw Payloads

Because Firefox collects thousands of individual metrics, scrolling through them manually is inefficient. The about:telemetry page includes a search bar in the upper-right corner. Typing a keyword—such as memory, tab, places, or gfx—instantly filters the currently selected section to show only matching metrics. If you are on the Home section of the page, the search bar will query across all sections simultaneously.

If you want to inspect the data outside of the graphical interface, click Raw JSON at the bottom of the left-hand menu. This view strips away the charts and tables, presenting the exact, unformatted JSON text payload that Firefox transmits to Mozilla. From this screen, you can use Firefox's built-in JSON viewer to collapse trees, filter keys, or save the entire payload to your computer for independent auditing.
