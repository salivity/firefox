Disabling vs Hiding Pocket in the Firefox Web Browser

This article explains the technical and functional differences between completely disabling the Pocket integration in Mozilla Firefox via the extensions.pocket.enabled configuration setting and simply removing the Pocket icon from the browser's toolbar. While hiding the icon merely cleans up your visual interface, changing the advanced configuration preference shuts down the feature entirely at the system level, which impacts context menus, New Tab recommendations, and background browser processes.

Hiding the Pocket Icon from the Toolbar

Removing the Pocket icon from the toolbar—done by right-clicking the icon and selecting "Remove from Toolbar"—is a purely cosmetic change. When you choose this method, the Pocket integration remains fully active within Firefox.

Here is what happens when you only hide the icon:

  • The Feature Remains Active: The underlying system add-on for Pocket continues to run in the background.
  • Context Menus Stay Intact: If you right-click on a webpage or a link, you will still see options like "Save Page to Pocket" or "Save Link to Pocket" in the context menu.
  • New Tab Integration Continues: Pocket's "Recommended by Pocket" stories will still appear on your Firefox New Tab page unless you manually turn them off in the standard settings menu.
  • Resource Usage: Because the extension is still enabled, Firefox continues to allocate a small amount of memory and processing power to keep the integration ready for use.

Setting extensions.pocket.enabled to false

Changing the extensions.pocket.enabled preference to false within Firefox's advanced configuration page (about:config) is a system-level action. This method completely deactivates the built-in Pocket integration as if it were never installed.

Here is what happens when you disable the preference in about:config:

  • Complete Deactivation: The Pocket system add-on is turned off entirely and will not load when you start Firefox.
  • Total UI Removal: The Pocket icon is removed from the toolbar and the customization palette. Additionally, all Pocket-related options are stripped from your right-click context menus and the address bar.
  • New Tab Stories Disappear: The "Recommended by Pocket" section on the New Tab page is automatically disabled and hidden, preventing Firefox from fetching story recommendations in the background.
  • Zero Resource or Network Usage: Firefox will no longer use memory to run Pocket scripts, and the browser will stop making background connections to Pocket's servers to fetch data.

Which Method Should You Use?

If you occasionally use Pocket or enjoy reading the recommended articles on your New Tab page, but you want a cleaner-looking browser toolbar, simply hiding the icon is the best approach.

If you never use Pocket, want to declutter your right-click context menus, or want to maximize your browser's performance and privacy by stopping unnecessary background connections, setting extensions.pocket.enabled to false is the definitive solution.
