Middle-Click Autoscrolling in Firefox on Linux and macOS

This article explains the mechanics of the middle-click autoscrolling feature in the Firefox web browser and provides step-by-step instructions on how to enable it on Linux and macOS systems. While this feature is enabled by default on Windows, Firefox disables it out of the box on macOS and Linux due to operating system-specific mouse behaviors. By following the straightforward methods below, you can quickly activate and use this navigation tool.

How Middle-Click Autoscrolling Works

Autoscrolling allows you to navigate long web pages hands-free without repeatedly spinning the scroll wheel or dragging the scrollbar.

  1. Activation: Press the middle mouse button (typically by clicking down on the scroll wheel) anywhere on a webpage that is not a link or an input field.
  2. The Origin Point: A circular icon with directional arrows will appear on the screen, marking the origin point.
  3. Directional Movement: Move your mouse cursor away from the origin icon. Moving the cursor below the icon scrolls the page down, while moving it above scrolls the page up. It also works horizontally if the page is wide enough.
  4. Speed Control: The scrolling speed is determined by the distance between your cursor and the origin icon. Moving the cursor slightly away results in a slow, readable scroll. Moving the cursor far away from the icon results in rapid scrolling.
  5. Deactivation: Click any mouse button or press the Escape key to stop scrolling and return to the standard cursor. Alternatively, you can press and hold the middle mouse button, move the mouse to scroll, and release the button to stop immediately.

How to Enable Autoscrolling via Firefox Settings

The easiest way to enable this feature on both Linux and macOS is through the standard graphical settings menu.

  1. Open the Firefox browser.
  2. Click the menu button (three horizontal lines) in the top-right corner of the window.
  3. Select Settings from the dropdown menu.
  4. Ensure you are on the General tab on the left sidebar.
  5. Scroll down to the Browsing section at the bottom of the page.
  6. Check the box next to Use autoscrolling.

The setting takes effect immediately, and no browser restart is required.

How to Enable Autoscrolling via about:config

If you prefer using Firefox's advanced configuration page, or if the option is missing from your standard settings menu, you can enable it manually.

  1. Open a new tab in Firefox.
  2. Type about:config into the address bar and press Enter.
  3. Click the Accept the Risk and Continue button on the warning prompt.
  4. Type general.autoScroll into the search bar at the top.
  5. Double-click the general.autoScroll preference, or click the toggle icon on the far right, to change its value from false to true.

Resolving the Middle-Click Paste Conflict on Linux

On Linux, the middle mouse button is natively used by the operating system to paste currently selected text. When you enable autoscrolling in Firefox on Linux, both features remain active. If you middle-click on an empty part of a webpage, it will autoscroll; if you middle-click inside a text box, it will paste text.

If you find yourself accidentally pasting text into search bars or forms when trying to scroll, you can disable the middle-click paste function within Firefox:

  1. Navigate to about:config via the address bar.
  2. Search for middlemouse.paste.
  3. Toggle the value to false.

This change only affects Firefox and will not disable middle-click pasting in other Linux applications.
