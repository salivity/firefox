Import and Export CSV Passwords via Firefox about:logins

This article provides a step-by-step guide on how to manage your saved credentials in the Firefox web browser using plaintext CSV files. You will learn how to access the built-in about:logins menu to export your existing passwords for backup or migration, how to enable the file import feature if it is hidden in your browser version, and how to import an existing CSV password file directly into Firefox.

Accessing the Firefox Password Manager

To import or export passwords, you first need to open the Firefox password management menu:

  1. Open the Firefox web browser.
  2. Click on the address bar at the top of the window.
  3. Type about:logins and press Enter.

Exporting Passwords to a CSV File

Exporting your logins creates an unencrypted, plaintext CSV file containing your usernames, passwords, and website URLs.

  1. Inside the about:logins menu, click the three-dot menu icon located in the top-right corner of the page (below the browser's main menu button).
  2. Select Export Logins... from the dropdown menu.
  3. A warning prompt will appear reminding you that passwords are saved as readable text. Click the Export... button to proceed.
  4. If prompted, enter your computer's operating system password, PIN, or use biometrics to authorize the action.
  5. Choose a destination folder, name your file, and click Save.

Importing Passwords from a CSV File

Before importing, ensure your CSV file has columns labeled for the URL, username, and password (standard Firefox and Chrome exports are formatted correctly by default).

  1. Inside the about:logins menu, click the three-dot menu icon in the top-right corner.
  2. Select Import from a File... from the dropdown menu.
  3. Locate and select the plaintext .csv file on your computer.
  4. Click Open. Firefox will process the file and display a summary of the imported and updated logins.
  5. Click Done to close the summary window.

Troubleshooting: Missing "Import from a File" Option

If you are using an older version of Firefox or an operating system where the import option is hidden by default, you must enable it manually:

  1. Open a new tab, type about:config into the address bar, and press Enter.
  2. Click Accept the Risk and Continue.
  3. In the search bar at the top, type signon.management.page.fileImport.enabled.
  4. If the value is set to false, click the toggle icon on the far right of the row to change its value to true.
  5. Restart Firefox, return to about:logins, and the Import from a File... option will now be available in the three-dot menu.

Security Precaution

Because CSV files store your sensitive data in plaintext, anyone with access to the file can read your passwords. Once you have finished importing your passwords or moving them to a secure password manager, permanently delete the CSV file from your computer and empty your system's recycle bin or trash.
