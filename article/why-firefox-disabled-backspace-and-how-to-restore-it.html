Why Firefox Disabled Backspace and How to Restore It

In Firefox 86, Mozilla officially disabled the ability to use the Backspace key as a shortcut to navigate to the previous web page. This article explains that the change was made to prevent users from accidentally losing data while filling out online forms, and it provides a direct, step-by-step guide on how to restore the shortcut by modifying the browser.backspace_action preference in Firefox's advanced configuration settings.

Why Firefox Disabled the Backspace Shortcut

For decades, pressing the Backspace key in web browsers served as a convenient shortcut to go back to the previous page. However, this feature caused a widespread problem: accidental data loss.

When users were typing into online forms, text boxes, or web applications, they would occasionally click outside the text box by mistake. Taking the text box out of focus meant that the next time the user pressed the Backspace key to delete a typo, the browser interpreted it as a command to leave the page. Consequently, the browser would navigate backward, and everything the user had typed was instantly erased.

To solve this, Mozilla aligned Firefox with other major browsers like Google Chrome and Microsoft Edge, which had already removed the shortcut years prior. Instead of the Backspace key, Firefox now encourages users to use the Alt + Left Arrow shortcut (or Command + Left Arrow on Mac) to navigate back safely.

How browser.backspace_action Restores the Feature

Mozilla did not completely remove the code for the Backspace shortcut; they simply changed its default setting. The behavior of the Backspace key is controlled by a hidden preference called browser.backspace_action located in Firefox’s configuration editor.

This setting accepts three specific integer values:

  • 2 (Current Default): Pressing Backspace does nothing.
  • 1: Pressing Backspace scrolls up the current page ( pressing Shift + Backspace scrolls down).
  • 0 (Legacy Default): Pressing Backspace navigates back to the previous page (pressing Shift + Backspace navigates forward).

Steps to Re-enable the Backspace Key

You can restore the Backspace navigation shortcut in less than a minute by changing the preference value back to 0. Follow these steps:

  1. Open Firefox and type about:config into the address bar, then press Enter.
  2. A warning page may appear stating "Proceed with Caution." Click the Accept the Risk and Continue button.
  3. In the "Search preference name" box at the top of the page, type browser.backspace_action.
  4. Locate browser.backspace_action in the results list. You will see its value is currently set to 2.
  5. Double-click on the row (or click the Edit pencil icon on the far right) to change the value.
  6. Type 0 into the text box.
  7. Press Enter or click the blue Checkmark icon to save the change.

The change takes effect immediately. You can now close the configuration tab and use the Backspace key to navigate back to previous web pages just as you did in older versions of Firefox.
