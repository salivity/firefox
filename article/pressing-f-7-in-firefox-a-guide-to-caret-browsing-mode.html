Pressing F7 in Firefox: A Guide to Caret Browsing Mode

Pressing the F7 key in the Mozilla Firefox web browser activates Caret Browsing mode, a built-in accessibility feature that places a movable text cursor directly onto a webpage. This article provides a straightforward breakdown of what happens the moment you press F7, how the feature changes your keyboard navigation, the practical uses for the mode, and how to disable it.

The Confirmation Prompt

When you press the F7 key in Firefox for the first time, the feature does not activate immediately. Instead, a pop-up dialog box appears on the screen with the message: "Pressing F7 turns Caret Browsing on or off. This feature places a moveable cursor in web pages, allowing you to select text with the keyboard. Do you want to turn Caret Browsing on?"

You are presented with a few options in this prompt:

  • Yes: Activates Caret Browsing immediately.
  • No: Cancels the action and returns you to normal browsing.
  • Do not show this dialog box again: A checkbox that, if selected, allows the F7 key to toggle the mode instantly in the future without asking for confirmation.

A Blinking Cursor Appears

Once confirmed, a blinking vertical line—known as a caret or text cursor—appears directly on the webpage text. This makes the static webpage behave much like a document inside a word processor such as Microsoft Word or Google Docs. You can click anywhere on the text of a webpage to place the caret at that specific spot.

Changes to Keyboard Navigation

Enabling Caret Browsing fundamentally changes how your keyboard interacts with Firefox.

In standard browsing mode, pressing the Up and Down arrow keys scrolls the entire webpage vertically. In Caret Browsing mode, the arrow keys control the blinking cursor instead:

  • Up and Down Arrows: Move the cursor up or down one line of text at a time. The webpage will only scroll when the cursor reaches the very top or bottom edge of your current view.
  • Left and Right Arrows: Move the cursor one character to the left or right.
  • Ctrl + Left/Right Arrows (Command + Left/Right on Mac): Jumps the cursor one whole word to the left or right.
  • Home and End Keys: Moves the cursor to the beginning or the end of the current line of text, rather than jumping to the top or bottom of the entire webpage.

Selecting Text and Clicking Links

Caret Browsing allows you to interact with webpage content entirely without a mouse.

To highlight text, move the caret to the beginning of the desired text, hold down the Shift key, and use the arrow keys to expand the selection. Once highlighted, you can press Ctrl + C (or Command + C on Mac) to copy the text to your clipboard.

Furthermore, as you move the caret through the text using the arrow keys, it will eventually pass over hyperlinks and interactive buttons. When the caret is on a link, a focus ring will appear around it, and you can press the Enter key to open that link.

How to Turn Off Caret Browsing

To exit Caret Browsing mode and return your arrow keys to their normal scrolling behavior, simply press the F7 key again. Firefox will not show a confirmation prompt when turning the feature off; the blinking cursor will immediately disappear, and standard navigation will resume.
