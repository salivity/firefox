How to Always Show the Full URL in the Firefox Address Bar

By default, the Mozilla Firefox web browser simplifies the address bar by hiding the URL protocol (such as https://) and trimming trailing slashes from web addresses. While this creates a cleaner look, many users and developers prefer to see the exact, full URL at all times for security and convenience. This article provides a quick, step-by-step guide on how to disable URL trimming and force Firefox to display the complete web address using its advanced configuration settings.

Step 1: Open the Advanced Configuration Page

To change how Firefox displays URLs, you need to access its hidden settings menu.

  1. Open your Firefox browser.
  2. Type about:config into the address bar.
  3. Press Enter or Return on your keyboard.

Step 2: Accept the Warning

If this is your first time accessing the configuration page, Firefox will display a warning message stating "Proceed with Caution." This is a standard notice to prevent users from accidentally breaking browser functionality.

  1. Click the blue button labeled Accept the Risk and Continue.

Step 3: Locate the URL Trimming Preference

Now you will see a search bar at the top of the configuration page. You need to find the specific setting that controls how the address bar formats web addresses.

  1. In the "Search preference name" box, type or paste the following text: browser.urlbar.trimURLs
  2. You will see a single result appear below the search bar. By default, its value is set to true.

Step 4: Disable URL Trimming

To force Firefox to show the full URL, you must change this preference value from true to false.

  1. Double-click anywhere on the browser.urlbar.trimURLs row, or click the Toggle icon (two arrows pointing in opposite directions) on the far right side of the screen.
  2. Ensure the value changes to false.

Step 5: Verify the Change

The change takes effect immediately without needing to restart the browser.

  1. Open a new tab and visit any secure website.
  2. Look at the address bar. You will now see the full https:// or http:// protocol at the beginning of the web address, and the domain will no longer be trimmed.
  3. Close the about:config tab when you are finished.
