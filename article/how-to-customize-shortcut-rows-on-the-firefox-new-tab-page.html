How to Customize Shortcut Rows on the Firefox New Tab Page

This article explains how to change the number of shortcut rows displayed on the Mozilla Firefox New Tab page. You will learn how to adjust this layout using the standard Firefox settings menu to display between one and four rows, as well as an advanced configuration method to display five or more rows for maximum customization.

Method 1: Using the New Tab Page Settings (1 to 4 Rows)

If you want to display between one and four rows of shortcuts, you can easily adjust this directly from the New Tab page.

  1. Open Firefox and open a New Tab.
  2. Click the Personalize new tab (gear icon) located in the top-right corner of the page.
  3. In the panel that slides out, locate the Shortcuts section.
  4. Ensure the Shortcuts toggle switch is turned on.
  5. Click the row selection dropdown menu directly beneath the Shortcuts toggle.
  6. Select whether you want 1 row, 2 rows, 3 rows, or 4 rows.
  7. Click Close or click anywhere outside the panel to save your changes.

Alternatively, you can find this exact same dropdown menu by clicking the main Firefox application menu (three horizontal lines in the top-right corner), selecting Settings, and clicking on the Home panel on the left side.

Method 2: Using the Configuration Editor (5 or More Rows)

If four rows of shortcuts are not enough, you can bypass the standard limit using Firefox’s advanced configuration page.

  1. Open a new tab in Firefox.
  2. Type about:config into the address bar and press Enter.
  3. A warning page may appear. Click the Accept the Risk and Continue button to proceed.
  4. In the Search preference name box at the top, type or paste the following preference: browser.newtabpage.activity-stream.topSitesRows
  5. The preference will appear in the list below with a current number value (representing your current number of rows).
  6. Double-click on the preference, or click the Edit (pencil) icon on the far right.
  7. Type the exact number of rows you wish to see on your New Tab page (for example, 5 or 6).
  8. Press Enter or click the Save (checkmark) icon.

Your New Tab page will immediately update to reflect the new number of shortcut rows. If you return to the standard Firefox settings later, avoid touching the row dropdown menu, as doing so will reset your custom number back to the standard 1 to 4 limit.
