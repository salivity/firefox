How to Simulate Slow Network Speeds in Firefox

This article provides a step-by-step guide on how to simulate slow 3G, 4G, and offline network conditions in the Mozilla Firefox web browser. By utilizing the built-in Developer Tools and the network throttling dropdown menu, you can easily evaluate how websites load and perform under various connection constraints without altering your actual internet bandwidth.

Step 1: Open the Firefox Developer Tools

To access the network throttling feature, you first need to open the Developer Tools panel on the webpage you want to test. You can do this in one of three ways:

  • Keyboard Shortcut (Windows/Linux): Press Ctrl + Shift + I or simply press F12.
  • Keyboard Shortcut (Mac): Press Cmd + Option + I.
  • Mouse: Right-click anywhere on the webpage and select Inspect from the context menu.

Step 2: Navigate to the Network Tab

Once the Developer Tools panel opens at the bottom or side of your browser window, look at the top toolbar of the panel. Click on the Network tab. If you do not see it immediately, click the >> (More Tools) icon to reveal hidden tabs and select Network from the list.

Step 3: Locate the Network Throttling Dropdown

Inside the Network panel, look at the far right side of the secondary toolbar (just below the main Developer Tools tabs). You will see a dropdown menu that is set to No Throttling by default.

If your browser window is narrow, this option might be tucked away or require you to expand the Developer Tools area to make it visible.

Step 4: Select a Network Speed Profile

Click on the No Throttling dropdown menu to reveal a list of preset network conditions. Each preset simulates specific download speeds, upload speeds, and minimum latency. Select the profile that matches your testing needs:

  • Offline: Cuts off all network access to the tab, allowing you to test service workers and offline capabilities.
  • GPRS: Simulates an extremely slow mobile connection (50 Kbps download).
  • Regular 2G / Good 2G: Simulates legacy mobile data networks (250 Kbps to 450 Kbps download).
  • Regular 3G / Good 3G: Simulates standard 3G mobile networks (750 Kbps to 1.5 Mbps download).
  • Regular 4G / LTE: Simulates a standard 4G mobile connection (4 Mbps download).
  • DSL: Simulates a basic wired broadband connection (2 Mbps download).
  • WiFi: Simulates a standard wireless home or office network (30 Mbps download).

Step 5: Reload the Webpage to Test

Selecting a profile from the dropdown menu immediately applies the constraint to the current tab. To see how the webpage loads under the newly selected condition, refresh the page by pressing F5 (or Cmd + R on Mac).

For the most accurate results, perform a hard refresh by pressing Ctrl + Shift + R (or Cmd + Shift + R on Mac). This bypasses your browser cache and forces the page to download all assets from scratch using the throttled connection speed.

Alternative Method: Responsive Design Mode

You can also access the network throttling dropdown while testing mobile screen sizes.

  1. Press Ctrl + Shift + M (or Cmd + Option + M on Mac) to open Responsive Design Mode.
  2. Look at the toolbar directly above the simulated mobile screen.
  3. Click the No Throttling dropdown menu on the right side of that toolbar.
  4. Select your desired 3G, 4G, or Offline preset and refresh the page.

Returning to Normal Speeds

Your network speeds will remain throttled as long as the Developer Tools panel is open and a profile is selected. To return your browser tab to its normal internet speed, either change the dropdown menu back to No Throttling or simply close the Developer Tools panel entirely.
