What Was Firefox Hello? WebRTC Video Calling Explained

This article provides a complete breakdown of Firefox Hello, a defunct communication feature once built directly into the Mozilla Firefox web browser. It covers how the tool utilized WebRTC technology to enable plugin-free video and voice calling, its evolution into a real-time tab-sharing tool, its partnership with Telefónica, and the reasons why Mozilla ultimately discontinued the service in 2016.

The Introduction of Firefox Hello

Mozilla introduced Firefox Hello in December 2014 with the release of Firefox 34. Developed in partnership with the Spanish telecommunications company Telefónica and powered by the TokBox OpenTok platform, Firefox Hello was designed to make online communication frictionless. Unlike competitors such as Skype or Google Hangouts, Firefox Hello did not require users to download extra software, install browser plugins, or even create an account.

How It Worked Using WebRTC

The core technology behind Firefox Hello was WebRTC (Web Real-Time Communication). WebRTC is an open-source project that provides web browsers and mobile applications with real-time communication via simple application programming interfaces (APIs).

Because of WebRTC, Firefox Hello operated with extreme simplicity:

  • No Accounts Needed: A Firefox user simply clicked the "Hello" chat bubble icon in the browser toolbar to start a conversation.
  • Link Sharing: The browser generated a unique, shareable URL.
  • Cross-Browser Compatibility: The user sent this link to a friend or colleague. The recipient did not need to use Firefox; they could open the link and join the call using any WebRTC-compatible browser, such as Google Chrome or Opera.

Key Features and the Shift to Cobrowsing

Initially, Firefox Hello functioned primarily as a standard video and voice calling tool, complete with instant messaging capabilities. If a user decided to sign in with a Firefox Account, they could also maintain a contacts list to call other Firefox users directly without needing to generate a link every time.

In late 2015, Mozilla shifted the focus of Firefox Hello from general video calling to "cobrowsing" and collaboration. The updated feature automatically shared the active browser tab whenever a user initiated a call. This allowed two people to look at the same webpage simultaneously, making it easy to plan trips, shop online together, or collaborate on work projects in real-time.

Why Firefox Hello Was Discontinued

Mozilla officially removed Firefox Hello in September 2016 with the release of Firefox 49. There were several practical reasons for its removal:

  • Mission Accomplished: Firefox Hello was originally created to serve as a proof-of-concept to showcase the power of WebRTC. By 2016, WebRTC had been widely adopted across the internet.
  • Third-Party Adoption: Major communication platforms—including Facebook Messenger, WhatsApp, and Google Hangouts—began offering plugin-free browser calling using the exact same WebRTC standards, rendering a built-in browser tool redundant.
  • Browser Bloat: Many users felt that having a communication client baked directly into the browser caused unnecessary bloat. Removing it allowed Mozilla to streamline the browser and focus its engineering resources on core performance and security.
