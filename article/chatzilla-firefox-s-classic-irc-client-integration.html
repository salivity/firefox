Chatzilla: Firefox's Classic IRC Client Integration

This article explores Chatzilla, a historic Internet Relay Chat (IRC) client built entirely on Mozilla technologies, and examines its deep integration with the Firefox web browser ecosystem. Originally developed as a core component of the Mozilla Application Suite, Chatzilla evolved into a widely used extension for Firefox that allowed users and developers to communicate in real-time directly within their browser, until architectural changes in Firefox eventually ended its lifecycle.

What Was Chatzilla?

Chatzilla was a cross-platform IRC client written entirely in JavaScript, HTML, CSS, and XUL (XML User Interface Language), which was Mozilla’s proprietary markup language for user interfaces. Because it was built using web and browser technologies rather than compiled platform-specific code, Chatzilla could run on any operating system that supported the Mozilla platform, including Windows, macOS, and Linux.

It offered all standard IRC functionalities, including:

  • Multiple server connections.
  • Channel and private messaging.
  • UTF-8 character encoding support.
  • Direct Client-to-Client (DCC) file transfers and chats.
  • SSL/TLS encryption.

Because the message display window was rendered by Mozilla's Gecko layout engine, users could easily customize the look and feel of their chat windows using standard CSS stylesheets, known within the client as "Motifs." Furthermore, advanced users could write custom plugins in JavaScript to automate tasks and add new commands.

Origins in the Mozilla Application Suite

Before the release of the standalone Firefox browser, the Mozilla Foundation developed the monolithic Mozilla Application Suite, which bundled a web browser, an email client, an HTML editor, and an IRC client into a single application. Chatzilla was introduced in 2000 as the suite's built-in IRC client.

When the Mozilla Foundation decided to shift its focus to standalone applications—creating Firefox for browsing and Thunderbird for email—Chatzilla was separated from the main browser codebase. However, it remained a default, built-in component of SeaMonkey, the community-driven successor to the original Mozilla Application Suite.

Integration with the Firefox Ecosystem

For Firefox users, Chatzilla was made available as an installable browser extension. Its shared codebase with Firefox allowed for a level of integration that standalone desktop IRC clients could not match.

Unified User Interface Once installed as an add-on, Chatzilla could be launched as a separate window using the Firefox runtime, or it could be opened directly inside a standard Firefox browser tab. This allowed users to manage their chat rooms alongside their web browsing sessions without switching applications.

Protocol Handling Installing Chatzilla automatically registered the irc:// and ircs:// (secure IRC) URL protocols within Firefox. When a user clicked an IRC link on a webpage, Firefox would automatically launch Chatzilla, connect to the specified server, and join the designated channel.

Shared Resources and Security Instead of maintaining its own networking stack, Chatzilla utilized Firefox’s internal networking libraries (Necko) and security components (Network Security Services). This meant Chatzilla inherited the browser's proxy settings, certificate management, and SSL/TLS capabilities automatically.

The Mozilla Community Hub Historically, the Mozilla project used IRC as its primary communication medium for developers, testers, and contributors. Because Chatzilla was easily accessible via the Firefox Add-ons repository, it became the default gateway for power users and new contributors to join the irc.mozilla.org network, report bugs, and collaborate on the development of Firefox itself.

Deprecation and End of Life

Chatzilla’s deep integration with Firefox was ultimately the cause of its demise. The client relied heavily on XUL for its interface and XPCOM (Cross-Platform Component Object Model) for low-level access to raw TCP network sockets, which are required for the IRC protocol.

In November 2017, Mozilla released Firefox 57, codenamed "Firefox Quantum." This update completely overhauled the browser's architecture and permanently dropped support for legacy XUL and XPCOM extensions in favor of the modern, secure WebExtensions API.

Because the WebExtensions API did not allow add-ons to make raw TCP socket connections, Chatzilla could not be ported to the new Firefox architecture. With the release of Firefox 57, Chatzilla ceased to function in modern versions of the browser, marking the end of its integration with the Firefox ecosystem.
