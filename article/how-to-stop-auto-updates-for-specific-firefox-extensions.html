How to Stop Auto-Updates for Specific Firefox Extensions

Firefox allows users to manage extension updates both globally and individually. While keeping add-ons updated is generally recommended for security and stability, there are times when a new update breaks functionality, removes a feature you rely on, or introduces unwanted changes. This article provides a step-by-step guide on how to disable automatic updates for a single extension in the Firefox web browser while keeping automatic updates enabled for all your other add-ons.

Step 1: Open the Add-ons Manager

Open your Firefox browser and navigate to the Add-ons Manager. You can do this quickly by typing about:addons into the address bar and pressing Enter. Alternatively, you can use the keyboard shortcut Ctrl + Shift + A (Windows/Linux) or Cmd + Shift + A (Mac), or click the three-line menu icon in the top-right corner and select Add-ons and themes.

Step 2: Verify Global Update Settings

Before changing individual settings, ensure that your global automatic updates are still enabled.

  1. Click on Extensions in the left-hand menu.
  2. Click the gear icon (Tools for all add-ons) located in the top-right area of the page.
  3. Make sure there is a checkmark next to Update Add-ons Automatically. If there is not, click it to enable global updates.

Step 3: Select the Specific Extension

From the main Extensions list, find the specific extension you want to stop from updating. Click directly on the name of the extension to open its management page.

Step 4: Turn Off Automatic Updates

Once you are on the extension's specific page, you will be in the Details tab by default.

  1. Scroll down toward the bottom of the Details section.
  2. Locate the Allow automatic updates setting.
  3. By default, this is set to Default, which follows your global settings. Change this setting by selecting the Off radio button.

Once Off is selected, Firefox will immediately stop downloading and installing updates for this specific extension. All of your other extensions that remain set to Default will continue to update automatically in the background.

How to Manually Update the Extension Later

When you set an extension's automatic updates to Off, a new option called Check for Updates will appear right below the setting. If you ever decide you want to update this specific extension in the future without turning automatic updates back on, simply return to this page and click Check for Updates.
