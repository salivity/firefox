How to Use Multiple Picture-in-Picture Windows in Firefox

This article explains how the Mozilla Firefox web browser enables users to open and manage multiple Picture-in-Picture (PiP) floating video windows simultaneously. You will learn the technical approach Firefox uses to bypass single-video limitations, the exact steps and shortcuts required to pop out several videos at once, and how to manage these floating media players for effective multitasking.

How Firefox Enables Multiple PiP Windows

Most Chromium-based browsers rely strictly on the standard W3C Picture-in-Picture Web API, which restricts the browser to a single active PiP session at any given time. Firefox bypasses this limitation by utilizing a custom, browser-level implementation.

Instead of restricting the feature to a single web API instance, Firefox detects HTML5 video elements independently across all open tabs. When a user triggers the PiP function, Firefox generates a separate, lightweight, always-on-top system window for that specific video stream. Because the browser treats each video player as an isolated process, you can spawn as many floating windows as your computer's hardware and screen real estate can support.

Steps to Open Multiple Videos at Once

Popping out multiple videos in Firefox requires the same action repeated across different video streams, whether they are on the same webpage or in entirely different tabs.

  1. Locate the first video: Start playing a video on any website.
  2. Trigger the PiP toggle: Hover your mouse cursor over the video. A small Picture-in-Picture icon (a rectangle with a smaller shaded rectangle inside) will appear on the right side of the video frame. Click this icon to pop the video out.
  3. Locate the next video: Navigate to another video on the same page or open a new tab and play a second video.
  4. Repeat the action: Hover over the second video and click the PiP toggle icon. A second floating window will immediately appear without closing the first one.

Alternative Methods to Trigger PiP

If a website hides the standard Firefox PiP toggle button, you can force multiple videos into floating windows using these alternative methods:

  • Context Menu: Right-click directly on the video player, then click "Watch in Picture-in-Picture" from the menu.
  • Double Right-Click (YouTube): On sites like YouTube that use custom right-click menus, rapidly right-click the video twice to reveal the native Firefox context menu, then select the PiP option.
  • Address Bar Icon: If a page has an active video, a PiP icon may appear on the right side of the Firefox address bar. Clicking it will pop out the primary video on that page.
  • Keyboard Shortcuts: Press Ctrl + Shift + ] on Windows and Linux, or Command + Shift + Option + ] on macOS. Note that the keyboard shortcut primarily targets the first playing video on the active tab.

Managing Your Floating Video Windows

Once you have multiple PiP windows open on your screen, Firefox allows you to control each one independently:

  • Moving and Resizing: Click and drag the center of any floating window to move it around your screen. Click and drag the edges or corners of a window to make it larger or smaller.
  • Corner Snapping: If you drag a PiP window toward the edge of your monitor, it will automatically snap into the nearest corner to stay out of the way of your workspace.
  • Playback Controls: Hover over any active PiP window to access individual controls for play/pause, volume mute/unmute, fullscreen mode, and timeline scrubbing (moving forward or backward by 5-second intervals using the arrow keys).
  • Subtitles and Captions: If captions are enabled on the source video (such as on YouTube or Netflix), Firefox will automatically render and scale those subtitles individually inside each corresponding PiP window.
  • Closing: Click the "X" in the top-right corner of a floating window to close the PiP view while keeping the source tab open, or click the "Back to tab" icon in the top-left corner to return the video to its original webpage.
