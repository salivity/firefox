Inspecting Firefox Cache Using the about:cache Page

This article provides a straightforward guide on how to use the built-in about:cache diagnostic page in the Mozilla Firefox web browser. By following the steps below, you will learn how to view the current storage sizes of your disk and memory caches, find the exact local file paths where cached data is saved, and inspect the detailed metadata of individual cached web files.

Accessing the Cache Information Page

To begin inspecting your cache, you need to access Firefox's internal network storage page:

  1. Open the Firefox web browser.
  2. Click the address bar at the top of the window.
  3. Type about:cache and press Enter.

You will be presented with a page titled "Information about the Network Cache Storage Service." This page is primarily divided into two main sections: memory (data stored temporarily in your system's RAM) and disk (data stored on your computer's hard drive).

Checking Cache Sizes and File Locations

The main about:cache screen immediately displays the size and location details for both your memory and disk caches. Looking at either section, you can interpret the data using the following fields:

  • Number of entries: This shows the total amount of individual files (images, scripts, stylesheets) currently held in that specific cache.
  • Maximum storage size: This indicates the maximum amount of space (in KiB) that Firefox is permitted to use for this cache type.
  • Storage in use: This displays the exact amount of space (in KiB) currently occupied by the cached files.
  • Storage disk location: This tells you where the files live. Under the memory section, this will read "none, only stored in memory" because the data is held in your RAM. Under the disk section, this displays the exact folder path on your computer's operating system where the physical cache files are saved. You can copy and paste this path into your system's file explorer to view the raw cache folders on your hard drive.

Inspecting Individual Cache Entries

If you want to see the actual files Firefox has stored, you can drill down into the specific entries for either the disk or memory cache.

  1. Locate either the memory or disk section on the about:cache page.
  2. Click the blue List Cache Entries link at the bottom of your chosen section.

A new page will load containing a massive table of every single item currently stored in that cache. The table provides several columns of data for each entry:

  • Key: The direct URL of the cached file (e.g., an image link or a website script).
  • Data size: The file size of that specific entry in bytes.
  • Fetch count: How many times Firefox has loaded this file from the cache instead of redownloading it.
  • Last Mod: The date and time the file was last modified.
  • Expires: The date and time when Firefox will consider this cached file outdated and delete or replace it.

Viewing Entry Metadata

To inspect a specific file in detail, click on its URL under the Key column in the cache entries list.

This opens the "Cache entry information" page for that specific item. Here, you can verify the exact storage location, see the security details of the connection used to download the file, read the raw HTTP response headers sent by the web server, and view a hexadecimal representation of the file's data at the very bottom of the page.
