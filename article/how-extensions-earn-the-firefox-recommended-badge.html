How Extensions Earn the Firefox Recommended Badge

This article outlines the strict security and usability standards an extension must meet to receive the "Recommended" badge in the Firefox Add-ons store. Mozilla's curation team evaluates potential extensions through rigorous manual code reviews and user experience assessments to ensure only the safest, highest-performing, and most intuitive tools receive this distinction.

Security Criteria

To protect users from malicious actors and data breaches, Mozilla enforces the highest security standards for Recommended extensions.

  • Manual Code Review: Unlike standard extensions that may only undergo automated checks, every single update to a Recommended extension must pass a manual, line-by-line code review by Mozilla security experts before it goes live to users.
  • Principle of Least Privilege: The extension must only request the minimum browser permissions necessary for its core functionality. Over-reaching permissions will result in immediate disqualification.
  • Self-Contained Code: The extension cannot load or execute remote code. All scripts and logic must be contained within the downloadable package so Mozilla can verify everything the extension does.
  • No Obfuscation: Developers are prohibited from hiding or obscuring their code. If the code utilizes build tools or minifiers, the developer must provide Mozilla with the original source code and instructions on how to reproduce the build.
  • Strict Privacy Compliance: User data collection must be minimal and directly related to the extension's purpose. The developer must provide a clear privacy policy, obtain explicit user consent before collecting personal or technical data, and transmit all data securely using HTTPS.
  • No Third-Party Monetization: Recommended extensions generally cannot include injected advertisements, bundled software, or stealthy affiliate links that compromise user trust and security.

Usability Criteria

Beyond being safe, a Recommended extension must provide an exceptional experience for the everyday Firefox user.

  • Intuitive Design: The extension must be easy to use right out of the box. Its user interface, menus, and settings must be well-designed, visually appealing, and easy for a non-technical person to understand.
  • Reliable Functionality: The add-on must fulfill its stated purpose effectively and consistently, free of major bugs, crashes, or broken features.
  • Optimal Performance: The extension cannot noticeably slow down the Firefox browser, cause web pages to lag, or consume excessive system memory and CPU resources.
  • Broad Audience Appeal: Recommended extensions are curated for the general public. While an extension can serve a specific purpose, it must be relevant and useful to a wide variety of internet users rather than a tiny, hyper-specific niche.
  • High-Quality Store Listing: The extension's page on the Firefox Add-ons store must feature an accurate description, clear explanations of its features, and up-to-date promotional text.
  • Active Developer Maintenance: The creator must actively support the extension. This means keeping it compatible with the latest versions of Firefox, fixing bugs in a timely manner, and being responsive to user feedback and reviews.
