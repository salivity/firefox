Why Mozilla Extended Firefox ESR 115 for Legacy OS Users

Mozilla's decision to extend security updates for the Firefox Extended Support Release (ESR) 115 branch provides a critical lifeline for users still running Windows 7, Windows 8.1, and macOS 10.12 through 10.14. This article provides an overview of the driving forces behind this extension, which primarily comes down to a surprisingly large remaining user base on these legacy systems, the prohibitive cost of hardware upgrades for many individuals and organizations, Mozilla's core mission to keep the web secure for everyone, and Firefox's unique position as the last major browser standing for these discontinued operating systems.

A Large Remaining User Base

The primary reason for the extension is simple: millions of people still use these older operating systems. According to Mozilla's own public telemetry data, a significant percentage of the global Firefox user base continues to run Windows 7, Windows 8.1, and older versions of macOS. While Microsoft and Apple have officially ended support for these platforms, the users themselves have not disappeared. Completely cutting off browser updates would immediately expose this massive group of people to severe cybersecurity threats.

Hardware and Financial Barriers to Upgrading

Many users on legacy operating systems are not staying on them by choice, but out of necessity. Upgrading to Windows 11 requires strict hardware specifications, such as specific newer processors and Trusted Platform Module (TPM) 2.0 chips, which older computers lack. Similarly, Apple routinely drops support for older Mac hardware with each new macOS release.

For users in developing nations, low-income households, small businesses, and underfunded public institutions, buying entirely new computers just to get a secure web browser is financially impossible. Mozilla recognized that extending ESR 115 was necessary to support users who are economically locked into their current hardware.

The Last Major Browser Standing

In early 2023, Google Chrome, Microsoft Edge, and most other Chromium-based browsers permanently ended support for Windows 7 and 8.1. The same occurred for macOS 10.12 through 10.14. When those browsers left the market, Firefox ESR 115 became the only major, modern web browser still providing security updates for these platforms.

Because Firefox became the default refuge for legacy OS users, Mozilla gained a loyal niche audience. Extending support allows Mozilla to retain this market share and maintain goodwill among users who were abandoned by larger tech giants.

Fulfilling Mozilla’s Core Security Mission

Running an unsupported operating system is inherently risky, as the OS itself no longer receives security patches. However, the vast majority of modern malware and cyberattacks occur through the web browser. An up-to-date browser acts as the first and most important line of defense for an outdated computer.

Mozilla operates under a manifesto that prioritizes an open, accessible, and safe internet for all. By continuing to backport critical security patches to the ESR 115 branch, Mozilla actively prevents widespread security compromises across the globe, aligning the technical decision with its foundational ethics.

Manageable Engineering Costs

Finally, extending an existing ESR branch is a calculated and manageable effort for Mozilla’s engineering team. Because the ESR 115 branch does not receive new features or major user interface changes, developers only need to port critical security fixes to it. While maintaining support for older operating system APIs is difficult in the long run, extending purely security-focused maintenance for an extra cycle offered a high return on user safety for a relatively low development cost.
